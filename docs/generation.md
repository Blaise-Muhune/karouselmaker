# Generation

Organic marketing carousels for **Instagram & TikTok**: **3–7 slides**, problem-first soft-sell, one post at a time.

## Project context

Each project stores niche, product/page to promote (`project_rules.product_to_promote`), tone, language, rules, and brand kit. Generation injects recent posts so topics/angles are not repeated.

## Input

- **Topic** (required) + optional notes
- Slide count: 3–7 or AI decides (prefer 5–7)
- Images: **Stock** | **Web (Brave)** | **My images** (library / Drive)
- One system template

## Output

Validated JSON slides + captions + hashtags + `similar_ideas` for next posts. Soft CTA on the last slide toward the product/handle.

## Removed

AI image generation, UGC character, LinkedIn long decks, viral shorts, video/TTS.
